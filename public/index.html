Webhook Setup

Configure your Bitrix24 and WhatsApp webhooks, then run auto-sync to import all leads.

🏢
Bitrix24 Webhook
Go to Bitrix24 → Developer Resources → Inbound Webhooks and copy the URL here. This is used to create contacts and leads automatically from WhatsApp.
📱
WhatsApp Webhook
Enter the URL where WhatsBox/Meta will deliver incoming messages, and the phone number of your WhatsApp Business channel.
⚡
Save & Auto-Sync
Auto-Sync pulls all existing contacts from Bitrix24 into this system so new WhatsApp messages instantly match them and create leads. Run this once after setup, and again whenever you add new contacts in Bitrix24.
